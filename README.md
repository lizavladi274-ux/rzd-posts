# Карьерные посты работодателей: сбор и индексы

Сбор постов карьерных каналов восьми работодателей в Telegram и четырёх групп во «ВКонтакте» в базу SQLite и выгрузка в таблицу с индексами охвата и вовлечённости.

| Файл | Что делает |
| --- | --- |
| `config.py` | список каналов и дата начала сбора |
| `parser.py` | полный сбор постов в базу `career_posts.db` |
| `update_stats.py` | обновляет просмотры и реакции у свежих постов |
| `export.py` | выгружает базу в `career_posts.csv` и считает индексы |
| `sources.py`, `storage.py` | сборщики Telegram и ВКонтакте, работа с базой |

Telegram собирается из открытой веб-версии `t.me/s/…`, ключ не нужен.
Для ВКонтакте нужен сервисный ключ доступа: программа спрашивает его при запуске и нигде не сохраняет.
Не записывайте ключ в код и не выкладывайте его на GitHub.

Запуск:
```
pip install -r requirements.txt
python parser.py          # всё; или: python parser.py telegram
python update_stats.py    # обновить счётчики за последние 30 дней
python export.py          # таблица career_posts.csv
```
